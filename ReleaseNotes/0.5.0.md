# MacBuddy 0.5.0

MacBuddy 0.5.0 is the first Apple Silicon-only release and the first release with secure, opt-in automatic updates.

- Adds Sparkle 2.9.4 update checks with EdDSA archive and feed verification.
- Corrects the memory headroom estimate to avoid counting speculative and purgeable pages twice.
- Makes the six-segment energy bar follow sustained memory pressure and CPU load more consistently.
- Adds CPU hysteresis and throttles process collection to reduce status flicker and background work.
- Reduces the arm64 app bundle and releases menu-panel resources when the panel closes.
- Adds the PolyForm Noncommercial License 1.0.0.

This is an unsigned beta without Apple Developer ID notarization. On first launch, Control-click MacBuddy in Finder and choose **Open**.

## 한국어

MacBuddy 0.5.0은 Apple Silicon 전용으로 전환한 첫 릴리스이자, 안전한 선택형 자동 업데이트를 지원하는 첫 릴리스입니다.

- EdDSA 아카이브·피드 검증을 사용하는 Sparkle 2.9.4 업데이트 확인 기능을 추가했습니다.
- speculative·purgeable 페이지를 중복 집계하지 않도록 메모리 여유 추정치를 바로잡았습니다.

- CPU 히스테리시스를 추가하고 프로세스 수집 간격을 제한해 상태 출렁임과 백그라운드 작업을 줄였습니다.
- arm64 앱 번들을 줄이고 메뉴 패널을 닫으면 관련 리소스를 해제합니다.
- PolyForm Noncommercial License 1.0.0을 추가했습니다.
